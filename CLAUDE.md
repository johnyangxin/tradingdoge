# CLAUDE.md

## Project Overview

TradingDoge - Stock display web application with TradingView charts and moving averages.

## Supported Stocks

- SPY - S&P 500 ETF
- BTC/USD - Bitcoin
- UVIX - Invesco NASDAQ 100 Low Volatility ETN
- GLD - SPDR Gold Shares

## Custom Skills

- /fetch-data: 获取股票数据
- /local-init: 启动本地开发环境（backend + frontend 同时运行）
