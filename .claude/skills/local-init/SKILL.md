---
name: local-init
description: 启动项目
---

When starting this project, automatically run both backend and frontend. Backend will automatically fetch latest data on startup:

```bash
cd backend && npm run dev
cd frontend && npm run dev
```

- Backend: http://localhost:3004
- Frontend: http://localhost:5173

## Commands

- Backend: `cd backend && npm run dev`
- Frontend: `cd frontend && npm run dev`
